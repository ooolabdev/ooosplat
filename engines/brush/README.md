OOOBrush ooo-v1.0.0 Windows x64 runtime. The headless brush-cli.exe is installed
as brush_app.exe for OOOSplat path compatibility; the viewer is excluded.
Use npm run setup:brush independently, or the automatic dev:local/build:local
preparation. The integration uses the CLI surface verified
by `scripts/verify-engines.ps1`; it does not start the viewer.
